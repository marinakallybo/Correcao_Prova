#  Volt Shop

Projeto de uma loja virtual de produtos tecnológicos, desenvolvido utilizando HTML, CSS e JavaScript. O sistema simula algumas funcionalidades de um e-commerce, como cadastro de produtos, carrinho de compras e finalização de pedidos.

##  Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- QRCode.js

##  Funcionalidades

- Listagem de produtos.
- Cadastro, edição e exclusão de produtos (CRUD).
- Carrinho de compras.
- Criação e armazenamento de pedidos.
- Simulação de pagamento por QR Code.
- Armazenamento de dados utilizando LocalStorage.

##  Identidade visual

O projeto utiliza uma paleta minimalista, com tons neutros e verde como cor principal.

| Variável | Código |
|---|---|
| Background | `#FFFFFF` |
| Card | `#FFFFFF` |
| Texto principal | `#181A2A` |

| Bordas | `#E5E7EB` |
| Cor principal | `#059669` |
| Sucesso | `#166A3A` |
| Erro | `#B42318` |

##  Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.

##  Observação

O projeto possui apenas finalidade acadêmica. O pagamento por QR Code é apenas uma simulação.
